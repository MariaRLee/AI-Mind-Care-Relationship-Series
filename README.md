# AI-Mind Care｜關係練習室 V1.1

本版依目前公開需求縮減內容，優先確認電腦與手機介面。

## V1.1 修改

1. 移除「安裝到手機」按鈕與 PWA 安裝程式。
2. 縮小首頁主標題與 Hero 區塊，避免桌機畫面過大與水平移動。
3. 放大頁首品牌：`♡ AI-Mind Care / 關係練習室`。
4. 加入完整夫妻關係使用說明：
   - 本系列以日常夫妻溝通、情緒覺察與關係反思為目的。
   - AI 所提供的「情緒翻譯」代表一種可能的理解角度，並非對個人心理狀態、人格、婚姻品質或心理健康進行診斷。
   - 每個人的感受與關係情境皆不同，真正的理解仍需要透過彼此的傾聽與對話建立。
   - 若關係中涉及暴力、威脅、安全問題或嚴重心理困擾，應尋求適當的專業協助。
5. 目前前台只顯示：
   - 夫妻關係｜第一季
   - EP01｜你根本不在乎我
   - EP02｜你為什麼一直滑手機？
6. 其他季度、其他關係系列與完整內容暫不顯示，留待後續版本加入。
7. 不含外部分析或追蹤程式。

## 加入影片網址

打開 `app.js`，在對應集數填入：

```js
videoUrl: "https://你的影片網址"
```

有網址時，該卡片會自動顯示「觀看短片」。
